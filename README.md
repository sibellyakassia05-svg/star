# ✨ Projetos Pessoais

### 🕷️ Spider

Um projeto desenvolvido em **Python**, utilizando a biblioteca Turtle para criar uma experiência visual e interativa.

O projeto explora desenhos matemáticos, animações, cores e projeção de formas em uma experiência chamada **Quantum Love**. ❤️

**Tecnologias:**
- Python
- Turtle
- Math
- Colorsys

📁 `spider/`
